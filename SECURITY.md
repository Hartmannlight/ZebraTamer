# Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when enabled:
https://github.com/Hartmannlight/ZebraTamer/security/advisories/new

If private reporting is unavailable, ask the maintainer via the GitHub profile for a private
reporting channel without posting exploit details or secrets in a public issue.
Never include production credentials or printer/network secrets in reports or logs.

Maintenance, supported release policy and limitations: [security release policy](docs/SECURITY_RELEASE_POLICY.md).
